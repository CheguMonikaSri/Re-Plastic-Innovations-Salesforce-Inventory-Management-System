# Re-Plastic-Innovations-Salesforce-Inventory-Management-System

## Overview
Re Plastic Innovations is a Salesforce-based inventory management system designed
to manage plastic waste, recycled products, customer orders, stock levels, and
automated restocking.

## Key Features
- Plastic waste and recycling center management
- Recycled product inventory management
- Order management
- Automatic low-stock detection
- Automated restock request creation
- Restock approval workflow
- Apex-based inventory updates
- Email notifications
- Validation rules and data security

## Salesforce Technologies
- Salesforce Lightning Experience
- Custom Objects and Fields
- Lookup Relationships
- Formula Fields
- Validation Rules
- Flow Builder
- Apex Classes
- Apex Triggers
- Salesforce Email Notifications

## Custom Objects
- Plastic Waste
- Recycling Center
- Recycled Product
- Order
- Restock Request

## Workflow

Customer Order
→ Check Stock
→ Sufficient Stock / Insufficient Stock
→ Create Restock Request
→ Approve Request
→ Update Product Stock
→ Send Email Notification

## Example

Initial Stock: 50  
Order Quantity: 150  
Restock Quantity: 100  
Final Stock After Approval: 150
